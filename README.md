# VK Music Online

Премиальный тёмный веб-прототип музыкального плеера.

## Текущий этап
- Адаптивный интерфейс для мобильных устройств и компьютера.
- Демо-каталог и панель управления плеером.
- Поиск по демонстрационному каталогу.
- Избранное сохраняется в localStorage.
- Подборки по настроению, перемешивание, повтор и таймер сна.
- Без сборщика: можно публиковать напрямую через GitHub Pages.
- Поиск текста песен через LRCLIB (если текст есть в каталоге).
- Панель подготовки подключения VK ID: хранит только публичный ID приложения в браузере.

## Важные ограничения
Каталог VK пока не подключён. Демо-треки не содержат аудио; для проверки воспроизведения можно импортировать локальные аудиофайлы. Поиск текстов LRCLIB работает отдельно и не даёт права воспроизводить соответствующие записи.

VK ID пока не подключён к завершённому OAuth-потоку: панель позволяет сохранить ID приложения, но это не означает, что пользователь уже авторизован. Следующий шаг — зарегистрировать приложение VK ID, настроить разрешённый redirect URL и корректно обработать OAuth-ответ. Доступ к аудиозаписям VK — отдельный вопрос и зависит от доступных официальных методов/разрешений. Не помещайте секреты и платёжные ключи в клиентский код GitHub Pages.

## Публикация
1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
4. После публикации сайт будет доступен по адресу `https://jdyxtramvaya-byte.github.io/vk-music-online/`.

Это ранний прототип, а не готовый сервис распространения музыки.
